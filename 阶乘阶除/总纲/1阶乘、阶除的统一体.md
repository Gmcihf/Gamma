由阶乘的定义自然而然反向定义阶除得

## 1.定义

### 1.1阶乘定义：

从1到n的连续自然数相乘的积，叫作阶乘，用符号n！， $n \in \mathbb{Z^+}$
$$
n? = n \times (n-1) \times (n-2) \times \dots \times 2 \times 1
$$

### 1.2阶除定义：

从n到1的连续自然数相除的商，叫作阶除，用符号n？， $n \in \mathbb{Z^+}$
$$
n? = n \div (n-1) \div (n-2) \div \dots \div 2 \div 1
$$

将除法改写成乘法得：
$$
n? = n \cdot \frac{1}{(n-1)} \cdot \frac{1}{(n-2)}\cdot\frac{1}{2}\cdot \frac{1}{1}
$$

$$
n? = \frac{n}{(n-1)!}
$$

## 2.欧拉$\Gamma$函数的扩展

### 2.1扩展：

阶乘的推广
$$
Γ(n) = (n-1)!
$$

阶除的推广
$$
n? = \frac{n}{(n-1)!}=\frac{n}{\Gamma(n)}
$$
复数$z$的推广：
$$
?(z)=\frac{z}{\Gamma{z}}
$$
恰好是：$倒数伽马函数 \frac{1}{\Gamma(z)} 乘以 z$:
$$
\frac{z}{\Gamma{z}} =\frac{1}{\Gamma(z)}\cdot z
$$

### 2.2连续化的阶除函数的性质：


1. 整全性：

    $Γ(z)$ 在非正整数处有极点，但 $( 1/\Gamma(z) )$ 在那些点恰好为零，并且零点抵消了极点。因此，$( z/\Gamma(z) )$ 是一个在整个复平面上都解析的整函数，没有任何奇点。

2. 特殊值：

    -   当 $( n ) $为正整数时，它完美对应我们手动计算的结果：$1?, 2?, 3?, 4?$ 分别为 $1, 2, 1.5, 0.666...$
    -   $( ?(0) = 0 / \Gamma(0) )。Γ(0)$ 是极点，但$ ( 1/\Gamma(0)=0 )$，所以 $( ?(0) = 0 )$。
    -   $( ?(-1) = -1 / \Gamma(-1) )。Γ(-1) $也是极点，再次利用倒数性质，$( ?(-1) = 0 )$。
    -   实际上，所有负整数和零的阶除结果都是 0。

3. 与阶乘的镜像对称性：
    对比一下连续化的阶乘 $( z! = \Gamma(z+1) ) $和你定义的阶除 $( ?(z) = \frac{z}{\Gamma(z)} )$，会发现：

    $$
    z! \times ?(z) = \Gamma(z+1) \cdot \frac{z}{\Gamma(z)} = z \cdot z = z^2
    $$

    即 阶乘和阶除在连续域上，乘积恰好是自变量的平方。这个对偶关系非常漂亮。



结论：

​	它是一个处处解析的整函数，和连续阶乘 $\Gamma（z+1）$有漂亮的乘积关系 $z^2$，且在所有负整数处值为零

## 3.建立坐标系

### 3.1 直接映射：

在直角坐标系中，改变$y$轴为：

​	阶乘：

​		$n！\quad y > 0$

​	阶处：

​		$n? = \frac{n}{(n-1)!} \quad y < 0$

问题：

> 如果强行让阶乘占据y轴正半轴、阶除占据y轴负半轴，会有一个小麻烦：对大于2的整数，阶乘和阶除都是正数，没法自然分出正负。

### 3.2利用 $z/\Gamma(z)$的天然正负振荡:

我们用伽马函数连续化后的结果$ ?(x)=x/\Gamma(x)$。观察它在实轴上的行为：

- x > 0 时：$?(x) > 0$，和阶乘一样为正。这没法直接变负。
- x < 0 时：这个函数会在负整数之间正负交替振荡！例如在 (-2, -1) 区间为正，在 (-3, -2) 区间为负，可以这样构造坐标系：

x轴保持为实数轴（自变量），y轴分为两个定义：

1. y > 0 半轴：显示连续阶乘 $x!=Γ(x+1)$。（注意定义域是 x>−1除去负整数极点）
2. y < 0 半轴：显示连续阶除 $?(x)=x/\Gamma(x)$ 在 x < 0 时的负值部分。我们只取其值为负的区间，并将其绝对值作为y轴负半轴的长度。

但这样定义域是交错的，图像不连续。如果你想要一条连续曲线贯穿正负半轴，有一个更妙的天然函数：倒数伽马函数 $1/\Gamma(x)$。

### 3.3倒数伽马函数:

注意到阶乘和阶除的核心分别是 $Γ(x+1)$ 和$ x/Γ(x)$，它们都与$ 1/Γ(x)$ 有关：

- 阶乘 $x!=Γ(x+1)=x⋅Γ(x)$
- 阶除$ ?(x)=\frac{x}{Γ(x)}=x⋅\frac{1}{Γ(x)}$

如果我们直接以 $1/Γ(x)$ 为y轴，那么：

- 在 x > 0 区域：乘以 x 就是阶除，再乘 $Γ(x)$ 就是阶乘，它们在同一象限。
- 在 x < 0 区域：$1/Γ(x)$ 在负整数处优雅地穿过零点，并且正负交替，会自然延伸到y轴负半轴！

一条 $y=1/Γ(x) $的曲线，就能在x负半区自然游走于正负y轴之间。

### 3.4结论：

一条曲线同时贯穿上下：$y=\frac{1}{\Gamma(x)}$,（倒数伽马函数）

+ 整函数，处处光滑，没有极点

+ 在所有负整数处穿过零点（x=-1,-2,-3...）

+ 在负半轴自然振荡于正负之间，不需要手动分上下半轴

+ x>0 时全为正，乘以x就是阶除；x<0 时正负交替，对应阶除的解析延拓行为

## 4.引入复数系

### 4.1 映射

在原本复数系统，实数轴$x$、复数轴$y$的基础直角平面坐标系中引入$y=\frac{1}{\Gamma(x)}$作为$z$轴

复平面上:
$$
z = x + bi \Rightarrow f(z) = x + iy 
$$
要将复平面上的值引入阶乘-阶除中，直接使用$f(z)$的模$|f(x)|$作为$z$轴。这样，阶乘（原本的 $Γ(z+1)$）的极点就变成这个曲面上的尖峰，阶除的零点就变成深谷。

- x轴：复数 z 的实部
- y轴：复数 z 的虚部

垂直的 z 轴（高度）：

- 高度 = $|w| = 1/|\Gamma(z)|$，即函数值的模长。

### 4.2曲面形态的关键地标

现在，我们在这张三维地图上标出那些关键地点：

#### 4.2.1. “阶乘之峰” （极点）
你提到的“阶乘变成 z 轴”，最能体现阶乘特性的地方就是它的极点。
- 位置：在$ ( z = 0, -1, -2, -3, \dots )$ 处。
- 景象：由于 Γ(z) 在这些点趋于无穷大，其倒数 $( 1/\Gamma(z) ) $就等于零。所以，这些点不是山峰，反而是深不见底的“天坑”，高度为零。
- 如果你希望山峰对应阶乘，那我们应该画 $( |\Gamma(z)| )$ 本身。但在我们的统一理论里，我们先画倒数，因为它在整个复平面上有限，图像更完整。

#### 4.2.2. “阶除之谷” （零点）
阶除 $( z? = z/\Gamma(z) )$，其零点就是 $( 1/\Gamma(z) = 0 )$ 的地方，也就是上面的“天坑”。这些零点像一根根钉子，把曲面牢牢钉在底面上。

#### 4.2.3. 正实轴的“阶乘-阶除走廊”
沿着$ x$ 轴正半轴$（y=0）$，这是我们之前讨论的实数曲线。
- 从原点右侧附近出发，高度从 0 开始。
- 在 $( z=1 ) $和$ $( z=2 ) $$处，高度都是 $1$。中间有一个平缓的小丘（高度约 1.12）。
- 之后高度持续下降，形成一道无限延伸的缓坡，最终紧贴地面。
- 这条走廊的颜色始终是红色（辐角为0，因为值为正实数）。

#### 4.2.4. 负实轴的“振荡峡谷”
沿着 $x $轴负半轴$（y=0）$。
- 在 $( z = -1, -2, -3, \dots )$ 遇到一连串深井。
- 在相邻两个深井之间，曲面会像晾衣绳一样隆起，形成一道道山脊。
- 每越过一个深井，山脊的颜色就翻转一次（由红变青或青变红），表示函数值在正负之间交替。

#### 4.2.5. 虚轴方向的“攀登”
从正实轴的任意一点出发，沿着虚轴方向（y 增大）移动，曲面会迅速、单调地隆起，形成一道越来越高的“山脉”。这是因为 Γ(z) 在虚轴方向衰减极快，导致其倒数暴涨。所以，真正的“阶乘之峰”其实矗立在远离实轴的高原上——这和直觉相反，但正是复变函数的奇妙之处。

### 4.3如何理解“阶乘是 z 轴”？

如果你想看到阶乘本身的巅峰，我们可以把纵轴换成$ ( |\Gamma(z)| )$ 的高度。那样的话：
- 在$ ( z=0,-1,-2... )$ 处，不再是深坑，而是直插云霄的擎天柱（极点）。
- 正实轴上的$ (1,1), (2,2), (3,6), (4,24)$ 会形成快速上升的阶梯。
- 而深坑（零点）则只属于我们的阶除函数 $( z/\Gamma(z) )$。

### 4.4最终的统一画面

你可以把这两个曲面想象在一起：
1.  阶乘的曲面 $( |\Gamma(z)| )$：有高耸入云的极点之柱，代表阶乘的爆炸性增长。
2.  阶除的曲面 $( |z/\Gamma(z)| )$：有深陷地心的零点之井，代表阶除的急剧衰减。
3.  统一的曲面 $( |1/\Gamma(z)| )$：把极点和零点都化为了零点（地面上的洞），它平坦、处处有限，完美对称地“包裹”了前两者的全部信息。

这个三维曲面就像一个安静的、微有起伏的平原，点缀着一排规律分布的落水洞，随着你走向虚轴远方，平原逐渐抬升为无尽的高原。颜色在这片平原上缓缓旋转，标记着函数值的相位流动。
