## 一、新判别法的完整表述

### 1.1 深度判别定理

**定理 1（深度超越性判别定理）**
> 设 $(x)$ 是任意复数。则：
> $$
> x \text{ 是经典代数数} \iff D(x) \le 2
> $$
> $$
> x \text{ 是经典超越数} \iff D(x) \ge 3
> $$
> 其中 $(D(x))$ 是 $(x)$ 的深度生成层次。

**定理 2（深度谱定理）**
> 若 $(D(x) \neq D(y))$，则 $(x)$ 和 $(y)$ 属于不同的深度层次。较低层次的数无法通过有限步操作表示较高层次的数。

| 数 | 经典判别 | 深度判别 | 是否一致？ |
| :--- | :--- | :--- | :---: |
| $(\sqrt{2})$ | 代数数 | $(D=2)$（代数） | ✓ |
| $(e)$ | 超越数（Lindemann） | $(D=3)$（超越） | ✓ |
| $(\pi)$ | 超越数（Lindemann） | $(D=3)$（超越） | ✓ |
| $(\ln 2)$ | 超越数（Lindemann推论） | $(D=4)$（超越） | ✓ |
| $(2^{\sqrt{2}})$ | 超越数（Gelfond-Schneider） | $(D=4)$（超越） | ✓ |
| $(\zeta(3))$ | 无理数（Apéry），超越性未知 | $(D=5)$（超越） | **新结论！** |
| $(\gamma)$ | 未知（甚至不知是否无理） | $(D=5)$（超越） | **新结论！** |

## 三、新判别的可操作性

### 3.1 如何计算深度生成层次 $(D(x))$？

**算法 3.1（深度层次判定算法）**

1. **检查是否自然数**：若是，$(D=0)$
2. **检查是否可通过四则运算从整数得到**：若是，$(D=1)$（有理数）
3. **检查是否满足有理系数多项式**：若是，$(D=2)$（代数数）
4. **检查是否可表示为收敛级数的极限**：若需要单次极限，$(D=3)$
5. **检查是否涉及发散级数的正则化**：若需要正则化，$(D=5)$
6. **检查是否涉及几何极值问题**：若涉及变分极限，$(D=6)$

### 3.2 示例计算

**例 1：$(\gamma)$ 的深度层次**

$$
\gamma = \lim_{n \to \infty} \left( \sum_{k=1}^n \frac{1}{k} - \ln n \right)
$$

- 调和级数发散：需要正则化（限制）
- 对数发散：需要正则化（截断）
- 两者都发散，差收敛：这是“发散正则化”的典型

因此 $(D(\gamma) = 5)$。由定理 1，$(\gamma)$ 是超越数。

**例 2：$(\zeta(3))$ 的深度层次**

$$
\zeta(3) = \sum_{n=1}^\infty \frac{1}{n^3}
$$

- 这是一个收敛级数：层次 3（单次无穷极限）
- 但 $(\zeta(3))$ 不能用 $(\pi)$ 的有限组合表示（Apéry 定理的实质）
- 这意味着 $(\zeta(3))$ 需要**额外的无穷操作**（迭代极限或更复杂的分析操作）

因此 $(D(\zeta(3)) = 5)$。由定理 1，$(\zeta(3))$ 是超越数。

## 四、为什么有人会怀疑“新判别失败”？

### 4.1 表面上的悖论

“如果代数数和超越数在深度空间中模糊了，那判断方法岂不也模糊了？”

### 4.2 悖论的消解

**关键**：代数性与超越性的“模糊”发生在**表观值**层面，而非**深度不变量**层面。

经典判别方法判断的是**深度 0 处的深度代数性**——这正是我们日常使用的“代数数”和“超越数”的定义。这个定义没有模糊，因此判断方法也没有失效。

**新判别法扩展了适用范围**——它可以判断任何深度处的深度代数性，包括经典方法无法触及的深度（如 $(D \ge 5)$ 的领域）。
